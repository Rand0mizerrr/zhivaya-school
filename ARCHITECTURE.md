# ARCHITECTURE — сайт «Живая школа»

Архитектура **этого репозитория** — публичного сайта-визитки вальдорфской школы «Живая школа» (Тюмень).

> Этот репозиторий содержит **только сайт**. CRM, аналитика и данные проекта живут в отдельном приватном контуре и сюда не входят.

## Что это
Статический сайт, без бэкенда и без базы данных. Весь контент захардкожен в `index.html`. Самодостаточен: системные шрифты, локальные изображения, без внешних зависимостей и сборки.

## Пользователь и путь
Один тип пользователя — **посетитель** (родитель):
читает страницу → при желании жмёт «записаться» → форма копирует текст заявки в буфер обмена и открывает Telegram (`t.me/+79324720279`), куда посетитель вставляет и отправляет сообщение. **Данные формы никуда на сервер не отправляются** — всё происходит в браузере.

## Структура репозитория
| Файл/папка | Назначение |
|---|---|
| `index.html` | вся разметка и контент (один файл) |
| `styles.css` | стили |
| `script.js` | интерактив: липкая шапка, мобильное меню, аккордеон методик, лайтбокс галереи, форма→Telegram, фильтр «Родительского клуба» |
| `img/` | изображения и эмблема (`logo.png`) |

## Хранение данных
Никакого. Нет БД, нет бэкенда, нет cookies/аналитики. Контакты и тексты — статически в `index.html`.

## Деплой
- **Хостинг:** GitHub Pages (source: ветка `main`, корень `/`). SSL автоматический.
- **Обновление:** правка файлов → коммит → `git push` в `main`. Сборка/публикация 1–3 минуты.
- **Live URL:** https://rand0mizerrr.github.io/zhivaya-school/

## Внешние зависимости
- **GitHub Pages** — хостинг.
- **Telegram** — приём заявок (клиентская ссылка, не API).
- **2ГИС** — карточка отзывов; на странице есть слот под официальный виджет отзывов (подключается кодом из кабинета 2ГИС).

## Восстановление после сбоя
`git clone` этого репозитория — достаточно, чтобы полностью восстановить и локально открыть, и опубликовать сайт. Внешнего состояния у сайта нет.
